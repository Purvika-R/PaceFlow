# Paceflow — Developer Productivity Dashboard

Task 1 dashboard built with React, Vite, Tailwind CSS, React Router, and Lucide React.

## Features

Responsive navigation, routed product pages, summary/progress cards, projects, task search, status/priority filters, loading skeleton, empty/error states, and local mock data.

## Run

`npm install` then `npm run dev`. Build with `npm run build`.

## Future backend integration

Mock data is kept separately in `src/data/mockData.js` so it can be swapped for REST API calls later.
